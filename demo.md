## Passo 2: blocos de código não viram título

O comentário dentro do bloco abaixo NÃO deve virar título:

```bash
# isto é um comentário de bash
echo "olá"
```

Nem dentro de um bloco de Markdown:

```markdown
# isto é um exemplo de markdown, não um título de verdade
```

    # bloco indentado com 4 espaços também é código

## Passo 3: render automático

Este arquivo já abre renderizado, sem rodar comando nenhum.

- **Anti-conceal:** ponha o cursor num título. A linha mostra o Markdown cru
  (`## Título`), sem o `◆`. Saia da linha e o `◆` volta.
- **Edição:** abaixo desta lista, digite uma linha nova `## Meu título` e saia
  dela. Ela deve virar título sozinha.
- **Toggle:** `:Nanquim` desliga o render (os `##` voltam e
  `:set conceallevel?` volta ao valor de antes). `:Nanquim` de novo liga.
- **Rolagem:** pule para o fim com `G` ou role com `Ctrl-f`. Os títulos lá
  embaixo já aparecem renderizados.
